# Getting Started

Knowledge is a privacy-first, post-quantum-secure knowledge substrate
for AI applications — on-device by default. Pick the path that matches
your role:

| I am a... | Start here | What you'll do |
|---|---|---|
| **Developer** embedding structured memory into an app or agent | [for-developers.md](for-developers.md) | Build from source, run the demo, embed the substrate. |
| **Operator** deploying hybrid/enterprise infrastructure | [for-operators.md](for-operators.md) | Deploy, configure, monitor, and run in production. |
| **Product team** evaluating what Knowledge enables | [for-product-teams.md](for-product-teams.md) | Understand capabilities, deployment modes, and integration patterns. |

## The 60-second version

- **What it is:** an encrypted, on-device store of evidence →
  observations → concepts → synthesized memory, with multilingual
  extraction, post-quantum crypto, and cryptographic forgetting.
- **Why it's different:** each user's data stays on their device.
  $0 marginal cost per user, works offline, no server to breach or
  subpoena.
- **How you use it:** embed the `ffi` / `napi` surface in a native app,
  or run the Go gateway for connector-driven, multi-tenant server
  deployments.
