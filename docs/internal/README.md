# Internal trackers

This directory holds the engineering trackers that used to live at
the repo root or under `docs/`. They are kept for contributors but
**are not part of the public documentation surface**.

| File | Purpose |
|---|---|
| [`PHASES.md`](./PHASES.md) | Phased delivery plan with goals, deliverables, and exit criteria. |
| [`PROGRESS.md`](./PROGRESS.md) | Per-phase deliverable status with the runtime / contract / stub taxonomy. |
| [`MODULE_STATUS.md`](./MODULE_STATUS.md) | Per-crate honest implementation status, including known security debt. |
| [`CHANGELOG.md`](./CHANGELOG.md) | Curated reverse-chronological milestones. |

If you are evaluating, integrating with, or contributing to the
substrate as a reader, start with the public docs instead:
[README.md](../../README.md), [docs/DESIGN.md](../DESIGN.md),
[ARCHITECTURE.md](../../ARCHITECTURE.md), and
[docs/PLATFORMS.md](../PLATFORMS.md).
