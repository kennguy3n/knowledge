  ╷
  │  WARNING: secrets.masterKey is empty. The substrate fails closed on
  │  boot without a 64-hex-char SQLCipher key. Generate one and upgrade:
  │
  │      MK=$(openssl rand -hex 32)
  │      helm upgrade {{ .Release.Name }} ./deploy/helm/knowledge \
  │        --set secrets.masterKey="$MK"
  │
  │  Treat this key as irrecoverable: losing it cryptographically erases
  │  all stored data; rotating it requires export + re-import.
  ╵
{{- end }}

{{- if and .Values.llamaServer.enabled (lt (int .Values.config.synthesis.globalConcurrency) (int .Values.llamaServer.replicaCount)) }}

  ╷
  │  WARNING: config.synthesis.globalConcurrency ({{ .Values.config.synthesis.globalConcurrency }})
  │  is below llamaServer.replicaCount ({{ .Values.llamaServer.replicaCount }}), so the gateway
  │  fair-share cap will leave part of the synthesis pool idle. Size it to
  │  the pool (≈ replicaCount × ~2 concurrent/replica) so it is saturated

  │      helm upgrade {{ .Release.Name }} ./deploy/helm/knowledge \
